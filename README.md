# 细胞防线（Cell Defense）

以**人体免疫系统**为主题的塔防策略小游戏：部署真实的免疫细胞干员，抵御病原体入侵，并在抽卡演出中还原细胞的**有丝分裂与分化**过程。

- 平台：安卓 APK ／ 任意浏览器（打开 [index.html](index.html) 即玩）
- 当前版本：**v1.7** ｜ 包名 `com.celldefense.game`
- 仓库：https://github.com/luyu31/cell-army

## 快速开始

**浏览器**：直接用浏览器打开 [`index.html`](index.html)（无需服务器）。

**安卓**：下载根目录下最新的 `细胞防线-vX.X.apk` 安装即可（需允许“未知来源应用”）。
